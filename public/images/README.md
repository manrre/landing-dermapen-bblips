# Guia de imagenes para la landing

Coloca aqui las imagenes finales de la landing. Idealmente usa `.webp` o `.avif`.
Si solo tienes `.jpg` o `.png`, tambien sirve; luego las optimizamos.

## Hero

Carpeta:

```text
public/images/hero/
```

Archivo recomendado:

```text
hero-prp-fibrina.webp
```

Uso:

- Hero principal concepto 1.
- Fondo azul petroleo, red de fibrina, plasma/PRP, estilo biomédico premium.

## Fondos abstractos

Carpeta:

```text
public/images/backgrounds/
```

Archivos recomendados:

```text
fibrina-dark.webp
fibrina-light.webp
```

Uso:

- `fibrina-dark.webp`: secciones oscuras de autoridad.
- `fibrina-light.webp`: secciones claras, educativas o formulario.

## Evolucion PRP / PRF

Carpeta:

```text
public/images/evolution/
```

Archivos recomendados:

```text
prp.webp
prf.webp
a-prf.webp
i-prf.webp
```

Uso:

- Cards de la seccion PRP -> PRF -> A-PRF -> I-PRF.
- Mejor si son imagenes cuadradas.
- No incluir texto dentro de la imagen; los titulos van en codigo.

## Aplicaciones profesionales

Carpeta:

```text
public/images/applications/
```

Archivos recomendados:

```text
bioestimulacion-facial.webp
regeneracion-capilar.webp
reparacion-tisular.webp
odontologia-prf.webp
infiltraciones-articulares.webp
```

Uso:

- Cards de aplicaciones por area profesional.
- Mejor si son imagenes cuadradas o 4:3.
- Evitar sangre, agujas agresivas, antes/despues y fotos de spa.
